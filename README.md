# Sales Performance Dashboard

## Project Overview
This project is an interactive Sales Performance Dashboard created using Microsoft Excel to analyze sales, profit, and business performance.

## Objectives
- Analyze sales and profit across different regions and product categories.
- Track monthly sales trends.
- Identify business performance using key performance indicators (KPIs).

## Tools & Skills
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers for interactive filtering
- Data Cleaning and Data Validation
- Conditional Formatting
- Excel Formulas

## Key Features
- Total Sales, Total Profit, Profit Margin, and Average Sales KPIs
- Region-wise and Category-wise Sales Analysis
- Category-wise Profit Analysis
- Monthly Sales Trend
- Interactive Region Slicer

## Project Files
- `Sales-Performance-Dashboard.xlsx` — Excel dashboard workbook

## Note
This is a practice project created using sample sales data for learning and portfolio purposes.
